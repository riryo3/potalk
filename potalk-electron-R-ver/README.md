# potalk-electron-R-ver

Potalker（ぽっと通話 非公式クライアント）の、Electron による**新作**です。既存の `potalk-mac/`（Electron の叩き台）とは別物で、Mac 版（`potalk-swift/`）・Windows 版（`potalk-win/`）・Linux 版（`potalk-linux/`）と同じ方式で作ります。見た目は、Mac 版に合わせています。いちばんの狙いは、**Linux で、クリックで開ける形（AppImage）**で届けることです。

- **方式**: 画面に出ない engine 窓で potalk.app をそのまま動かし、画面（`ui/`）だけを作り直します。
- **橋の JS**: `engine/bridge.js`・`engine/mic.js` は、Linux 版のものを写しています（`#peerNotice`・`#audioWarn` の読み取りを足してあります）。差し込み（`engine/patcher.js`）は、ほかの版と同じ内容です。
- **本体ページの扱い**: `https://potalk.app/` だけ、取得して差し込みを当てて返します（`main.js` の `installPagePatcher`）。ほかの通信は、そのまま通します。

## 動かす

```bash
npm install
npm start
```

## いまできること（0.0.15）

- ロビー（部屋の一覧・検索・更新）、部屋を作る、部屋に入る、退出
- 部屋：メンバー、ミュート、リアクション、🔄 つなぎ直す、エラー・お知らせの帯、回線（中継／直接）の表示、音量バー
- **ひとつの窓／分けた窓**：メニューの「表示」で切り替えます（次回の起動でも、そのまま）。
  - ひとつの窓：タブ（部屋・おたより・設定）。ひとことは、窓の下のドロワー（開くと、その高さのぶん窓が伸びます）。
  - 分けた窓：ロビー・部屋・ひとこと・おたより・設定が別窓。部屋に入ると、部屋の窓がロビーの右隣に開き、部屋の窓のボタンから、ひとこと・おたより・設定の窓を開きます。退出すると、補助の窓は閉じます。
- **表示サイズ** 50〜100%（10% 刻み。メニューの「表示」）：全部の窓の大きさと中身を、そろえて変えます。分けた窓の並びは、離れません。
- **吸着**：窓を動かして止めると、画面の端・ほかの窓の端（隣・端そろえ・上の高さ）に、14px 以内で合わせます。ロビーは、動かされる側にはなりません（Mac 版と同じ）。
- **ショートカット**（Windows・Linux は `Ctrl`、Mac は `⌘`）：`Shift+M` マイクのミュート、`Shift+S` スピーカーのミュート、`1` メインウインドウ、`2` 部屋、`3` ひとこと、`4` おたより、`5` 部屋の設定、`Shift+P` ひとつの窓／分けた窓、`]` `[` 次・前のタブ（ひとつの窓）。メニューの「通話」「ウインドウ」にもあります。入室していないあいだ、部屋まわりは灰色です。
- スピーカーのミュート、部屋の URL のコピー（🔗。押すと ✓ に変わります）：部屋の窓の、丸いボタン（ミュートと退出の間）
- **部屋一覧のドロワー**（ひとつの窓）：部屋の画面の端の「部屋一覧」の取っ手（または `Ctrl+L`）で、本体の横に、部屋の一覧が別の窓として開きます。本体の大きさは変わらず、動かしたり大きさを変えたりすると、一緒に付いてきます。左に出す余地がないときは右に、どちらにもないときは、本体を右にずらして左に出します。一覧で部屋を選ぶと、「移りますか？」の確認が本体に出ます。
- **プロフィール**：ロビーの自分のチップ（またはメニュー「ウインドウ」→「プロフィール…」）で、名前・アバター・名刺の設定・自衛ワードの画面が開きます。
- **自分の名刺の編集**（別窓）：アイコン画像（選ぶ→ドラッグと拡大で切り抜く→512×512 の JPEG）・ひとこと・お礼窓口・SNS（X・GitHub・Nostr は本人確認つき）。保存すると、端末にだけ保存され、相手が名刺を開いたときに、直接渡されます。本人確認は、手順の窓（鍵のコピー、投稿文、確認）が別に開きます。自分の名刺の画面にも、編集のボタンがあります。
- **名刺**：メンバーの行（絵文字・名前）を押すと開きます（アイコン・名前・状態・ひとこと・SNS のリンク。リンクは、確認してから開きます）。♥ で、無視の切り替え（確認つき）。配信部屋の、登壇・通話希望・マイクを使う。
- **窓の位置と大きさを覚えます**（窓の種類ごと。画面の外に出てしまう位置は使いません）。メニューの「ウインドウのレイアウトを初期化」で、初期の並びに戻します。
- 📌 最前面（ひとつの窓はタブの右端、分けた窓は部屋の窓の右上、メニューからも）
- 通話中に、部屋の窓や本体を閉じようとすると、確認します。
- 自衛ワード：含む部屋・人を、一覧に出しません（登録画面、書き出し・読み込み、入室中の通知）。ファイル形式は、Mac 版と同じです。分けた窓では、窓をまたいで同じ内容を使います。
- 日本語のメニュー。補助の窓には、メニューを付けません（Windows・Linux）。
- アイコンは、Mac 版と同じ「ぽ」（`build/icon.png`。AppImage と、窓に使います）。

## Linux 用の AppImage を作る

```bash
npm run dist:linux-arm64   # ARM（Apple シリコンの VM など）
npm run dist:linux-x64     # x64
```

`dist/` に `Potalker-<版>-<arch>.AppImage` ができます。

- **Mac で作るとき**：electron-builder が持ってくる `mksquashfs` が Intel 用で、Rosetta がないと動きません。`brew install squashfs` のあと、`~/Library/Caches/electron-builder/appimage/appimage-*/darwin/mksquashfs` を、`/opt/homebrew/bin/mksquashfs` へのリンクに差し替えます。
- **利用者に頼むこと（Ubuntu 22.04 以降）**：AppImage は、FUSE 2 を使います。`sudo apt install libfuse2t64`（22.04 は `libfuse2`）を、1 度だけ。ARM 版は、`zlib1g-dev` も要りました（起動部分が `libz.so` を探すため）。x64 版は、どの Ubuntu にもある `libz.so.1` を探すので、要らないはずです（起動部分の文字列を調べただけで、x64 の実機では、まだ試していません）。
- **サンドボックス**：AppImage は、一時フォルダに展開されて動くため、Chromium の `chrome-sandbox` に必要な権限（root 所有・4755）を付けられず、そのままでは起動しません。`build/afterPack.js` が、本体を `potalk-electron-r-ver.bin` にして、`--no-sandbox` を付けて呼ぶ起動スクリプトに差し替えます（「クリックで開ける」を優先した選択です）。`.deb` など、権限を付けて入れる配布を足すときは、この処理を AppImage だけに限ってください。

## 開発用

`POTALK_STEPS` に、`[{"at":ミリ秒, ...}, ...]` を渡して起動すると、順に実行します。

| キー | 内容 |
| --- | --- |
| `ui` | 窓の画面で JS を実行（結果は `[ui]` で出力）。`win:"room"` などで、窓を選びます |
| `eng` | engine 窓で JS を実行 |
| `shot` | 窓の画像を保存（パスを指定。`win` で窓を選ぶ） |
| `pm` | engine からの知らせを装う（例：`{"t":"room","d":{…}}`）。通話なしで、部屋の画面を試せます |
| `mode` / `scale` / `open` | ひとつの窓／分けた窓、表示サイズ、補助の窓（`chat`・`mail`・`settings`）を開く |
| `fn` | メニューの動作を呼ぶ（`showRoom`・`showChat`・`showMail`・`showSettings`・`showBanned`・`showMain`・`resetLayout`・`toggleSpk`・`toggleDrawer`） |
| `move` | 窓を動かす（`{"win":"chat","x":1860,"y":350}`）。吸着の確認に |
| `bounds` | 全部の窓の位置と大きさを出力 |
| `quit` | 終了 |

設定は、`userData` の `settings.json`（`mode`・`scale`・`pos`）に保存されます。試験のあとは、`mode:"single"`・`scale:100` に戻し、`pos` を消してください（メニューの「レイアウトの初期化」でも消えます）。
