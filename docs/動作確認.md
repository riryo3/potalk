# 動作確認の一覧

Potalker が、どんな環境で動いたか、の一覧です。**自分で確認したもの**と、**ほかの方の報告**を、分けて書いています。報告は、[Issue](https://github.com/riryo3/potalk/issues) か、作者の X（[@ryota_softwares](https://x.com/ryota_softwares)）へお願いします。機種と OS の版を、書いてもらえると助かります。

表の「起動」「通話」は、○＝確認した、—＝まだ確認していない、です。

## まだ確認していないもの

- Electron 版（Windows）：起動も通話も、まだです
- Electron 版（Linux）を、Linux の実機（x86_64）で
- Linux 版（Qt 製）：更新は終了しています
- Android 版の、モバイル通信での通話・長い時間の通話
- Android 版の、名刺の画像の登録・本人確認の実行・自衛ワードの通知
- Windows 版の、エラー時の帯・本人確認

「動いた」の報告は、増えたら、このページに足していきます。
